SPARROW V4 – PAYMENT SECTION

Diese Version enthält die V3 mit funktionierendem Discord-Link https://discord.gg/QxR2uwTGT.
NEU: Zahlungsmethoden ganz unten auf der Website mit lokalen SVG-Symbolen: PaysafeCard, PayPal, Visa, Mastercard, Apple Pay, Google Pay.

INSTALLATION:
1) ZIP entpacken.
2) Den gesamten Inhalt dieses Ordners in das Stammverzeichnis des GitHub-Repositories sparrow-website hochladen.
3) Die bisherigen gleichnamigen Dateien ersetzen. Der Ordner payment-icons muss vollständig hochgeladen werden.
4) Commit changes klicken und GitHub Pages Deployment prüfen.
5) Webseite neu laden (Strg+F5).

WICHTIG: Es sind derzeit nur geplante Zahlungsmethoden; kein Live-Checkout. Einzelne Zahlungsmethoden können erst nach Einrichtung beim Zahlungsanbieter als aktiv ausgewiesen werden. GitHub Pages speichert keine Zahlungsdaten. Niemals Geheimschlüssel in script.js hochladen.

Die lokalen Zahlungsmethoden-Grafiken sind vereinfachte, markenangelehnte Symbole, keine offiziellen Markenassets.
